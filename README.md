# student-grades

Predict the final grade (G3, 0-20) of a secondary-school student.

## Data
UCI Machine Learning Repository, *Student Performance* (id 320),
Cortez & Silva (2008), licence CC BY 4.0. https://archive.ics.uci.edu/dataset/320

## Install
```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pytest
```
